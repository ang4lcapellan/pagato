# Mint Flow - paquete para Figma

1. Arrastra `MintFlow_Pantallas_Importar_Figma.svg` al lienzo de Figma para importar todas las pantallas.
2. Usa los SVG individuales de Desktop y Mobile si prefieres importar solo una vista.
3. Instala la fuente Manrope antes de editar textos localmente.
4. Los colores principales son #16A085, #0B6B58, #F4FAF8, #FFFFFF y #102A27.
5. El archivo Brand/Logo_Billetera_Amable.svg contiene el lockup seleccionado.
