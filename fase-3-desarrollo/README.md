# Fase 3 — Desarrollo

Esta fase contiene la implementación técnica de PagaTo'.

- `app`: aplicación Next.js y pruebas automatizadas.
- `database`: modelo PostgreSQL, migraciones y verificaciones de seguridad.

Los archivos de entorno reales permanecen fuera de Git. Usa `app/.env.example` como referencia y crea `app/.env.local` únicamente en cada entorno local.
